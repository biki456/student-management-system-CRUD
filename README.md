A command-line CRUD application built using Python and MySQL to manage student records efficiently.

---

## Project Description

The Student Management System is a simple command-line application designed to perform CRUD operations on student data. It allows users to store, retrieve, update, and manage student information using a MySQL database.

---

## Features

- Add new student records
- View all student records
- Search students by ID or name
- Update existing student details
- Delete student records
- Filter students by course
- Export student records to CSV file

---

## Technologies Used

- Python 3
- MySQL
- mysql-connector-python

## How to Run the Project

### 1. Clone the repository
git clone https://github.com/biki456/student-management-system-CRUD.git

### 2. Install required dependency
pip install mysql-connector-python

### 3. Create the database in MySQL
CREATE DATABASE studentdb;


### 4. Run the application
python studentdb.py


Enter your MySQL password when prompted to connect to the database.
